# Project Scope: Veridian AI

## Problem

Enterprise teams ask ambiguous analytical questions across structured and unstructured data.

Example:

"Why did enterprise revenue drop in APAC last quarter despite increased marketing spend?"

This question requires:
- understanding business terms
- retrieving relevant documents
- querying structured tables
- comparing metrics
- synthesizing possible causes
- verifying evidence
- producing cited answers

## Why This Is Hard

1. Business terms are ambiguous.
2. SQL generation can be wrong.
3. Retrieval may miss key context.
4. LLMs may hallucinate explanations.
5. Structured and unstructured evidence must be combined.
6. Answers need citations and uncertainty.
7. The system must distinguish facts from inferred causes.

## What Veridian AI Does

Veridian AI converts natural language business questions into grounded analytical answers using:
- semantic query understanding
- hybrid retrieval
- SQL execution
- analytical planning
- evidence-grounded synthesis
- verification
- evaluation

## What This Project Is Not

- Not a generic chatbot
- Not a dashboard clone
- Not a production SaaS
- Not a perfect BI replacement
- Not a fine-tuned LLM project
- Not a tool that blindly trusts generated SQL

## Main Research-Engineering Question

How can we make LLM-based enterprise analytics systems more reliable, measurable, and explainable?
